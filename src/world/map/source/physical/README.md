# Physical Hydrography Sources

This directory contains the pinned physical-hydrography inputs used to build the Anatolia 10m runtime atlas.

## Source authority

The canonical runtime hydrography is generated by:

- Natural Earth 10m lakes
- Natural Earth 10m Europe lake supplement
- Natural Earth 10m river/lake centerlines
- Natural Earth 10m Europe river supplement

The fetcher pins the Natural Earth Vector repository revision. A source upgrade must be an explicit reviewed change.

## Runtime rule

`src/map/data/generated/anatolia-hydrography-10m.json` is the sole runtime authority for lakes and rivers in the physical atlas. Curated legacy lake/river coordinates must not be reintroduced as a second runtime source.

## Supplemental coverage backlog

The following major Anatolian features are tracked as source-coverage gaps rather than approximated geometry:

- Sapanca Lake
- Kızılırmak
- Yeşilırmak

They must only enter the generated atlas through a reproducible, license-compatible supplemental GIS source with a pinned revision and documented provenance.

Small or low-importance lakes and rivers are intentionally not promoted merely to increase source coverage. LOD remains responsible for visibility optimization after source geometry is generated.

## Geometry rules

- Coordinates remain WGS84 longitude/latitude (`EPSG:4326`).
- Source geometry is not hand-redrawn in runtime code.
- Duplicate geometry is removed during generation.
- Major river identity is canonicalized during generation.
- Coastline/land validation and lake exclusion are downstream physical-map contracts.
